# 蛛网小英雄（macOS）

一个常驻菜单栏的透明桌面伙伴。角色停在上一次落点；按住鼠标时向新位置发射白色蛛丝，拖动可微调锚点，松开后才沿弧线荡过去。原有点击仍会正常传递给桌面和其他应用。

也可以切换到“悬挂待机（下拉可挣脱）”：角色会用蛛丝静止悬挂在屏幕上沿。按住角色向下拖，拉动不足会弹回顶部；超过提示阈值后松手，角色会挣脱蛛丝并恢复摆荡模式。

## 下载与安装

> 当前安装包适用于 Apple 芯片 Mac，系统要求 macOS 13 或更高版本。

1. 下载最新版 [`SpideyDesktopHero-macOS.zip`](https://github.com/jackdoozo/spidey-web-swing-macos/releases/latest/download/SpideyDesktopHero-macOS.zip)。
2. 解压 ZIP，得到“蛛网小英雄.app”。
3. 首次启动时右键应用并选择“打开”。如果 macOS 仍然拦截，请前往 `系统设置 → 隐私与安全性`，在安全性提示下选择“仍要打开”。
4. 启动后菜单栏会出现图标，可切换角色样式、悬挂待机、暂停动画、把角色重新定位到鼠标或退出。

为了让角色读取全局鼠标操作，还需要打开：

`系统设置 → 隐私与安全性 → 辅助功能`

为“蛛网小英雄”开启权限，然后重新启动应用。菜单栏中的“请求辅助功能权限…”也可以打开系统授权提示。

当前版本采用临时签名，未经过 Apple 公证，因此第一次打开时出现安全提示属于正常现象。

## 三种角色

- 经典大头：红蓝配色、圆头大眼、短手短脚。
- 软萌团子：更圆、更软、粉嫩配色，像桌面玩偶。
- 漫画豆丁：黑色粗描边、面罩眼睛更有表情，摆荡姿势更动感。

角色显示高度约 52–62 像素，可在菜单栏随时切换。

## 重新构建

运行 `zsh scripts/build-app.sh`，成品会生成在 `dist/蛛网小英雄.app`。

需要 Swift 6 或更新版本。项目不使用第三方依赖，角色、蛛丝和动画均由 AppKit 原生绘制。
